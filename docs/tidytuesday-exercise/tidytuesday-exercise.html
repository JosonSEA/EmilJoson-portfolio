Tidy Tuesday Exercise

Introduction

For this week’s exercise, I analyzed the Tidy Tuesday dataset Bird Sightings at Sea. This dataset contains bird observations collected near New Zealand from 1969 to 1990, along with environmental conditions recorded from ships. This makes it possible to explore how environmental factors might influence bird abundance.

Overall, the exploratory analysis suggested that bird counts are highly variable and strongly influenced by species identity, while environmental variables may have smaller but still meaningful effects.

Research question and hypothesis

Question Do environmental conditions (wind speed, sea state, and season) influence bird abundance, and do these effects differ among the most commonly observed bird species?

Hypothesis Environmental conditions will influence bird counts, but species identity will likely explain a large portion of the variation, with different species responding differently to environmental factors.

Data preparation for modeling

To keep the modeling focused and manageable, I limited the analysis to the 10 most frequently observed species.

# keep only the top 10 most frequently observed species
top_species <- combined_data %>%
  count(species_common_name, sort = TRUE) %>%
  slice_head(n = 10) %>%
  pull(species_common_name)

# subset data for modeling and remove incomplete rows
model_data <- combined_data %>%
  filter(species_common_name %in% top_species) %>%
  select(count, wind_speed_class, sea_state_class, season, species_common_name) %>%
  drop_na()

I then split the data into training and testing sets. The test set was held aside and only used once at the end for final model evaluation.

# set seed for reproducibility
set.seed(123)

# split data into training (80%) and testing (20%)
data_split <- initial_split(model_data, prop = 0.8)
train_data <- training(data_split)
test_data  <- testing(data_split)

# check split sizes
nrow(train_data)
[1] 9719
nrow(test_data)
[1] 2430

Because bird counts were highly skewed, I log-transformed the outcome before modeling.

# log-transform the outcome to reduce skew and stabilize variance
train_data_log <- train_data %>%
  mutate(log_count = log(count + 1))

test_data_log <- test_data %>%
  mutate(log_count = log(count + 1))

Cross-validation was performed using the training data only.

# create 5-fold cross-validation splits using training data only
set.seed(123)
cv_folds <- vfold_cv(train_data_log, v = 5)

# define a recipe for preprocessing
# dummy variables are created for categorical predictors
bird_recipe <- recipe(
  log_count ~ wind_speed_class + sea_state_class + season + species_common_name,
  data = train_data_log
) %>%
  step_dummy(all_nominal_predictors())

# define evaluation metrics
model_metrics <- metric_set(rmse, rsq)

Model 1: Linear regression

The first model was a standard linear regression model fit using cross-validation.

# define a linear regression model
lm_model_cv <- linear_reg() %>%
  set_engine("lm")

# combine the recipe and model in a workflow
lm_workflow <- workflow() %>%
  add_recipe(bird_recipe) %>%
  add_model(lm_model_cv)

# fit the model using cross-validation on the training data
lm_cv_results <- lm_workflow %>%
  fit_resamples(
    resamples = cv_folds,
    metrics = model_metrics,
    control = control_resamples(save_pred = TRUE)
  )

# collect cross-validated performance metrics

Comparing model performance

To compare the three models fairly, I summarized RMSE and R-squared values from cross-validation.

# collect random forest metrics for later filtering
rf_metrics <- collect_metrics(rf_cv_results)

# summarize linear regression metrics
lm_metrics <- collect_metrics(lm_cv_results) %>%
  filter(.metric %in% c("rmse", "rsq")) %>%
  select(.metric, mean) %>%
  mutate(model = "Linear Regression")

# summarize penalized regression metrics using the best penalty value
glmnet_metrics <- collect_metrics(glmnet_cv_results) %>%
  filter(penalty == best_glmnet$penalty) %>%
  filter(.metric %in% c("rmse", "rsq")) %>%
  select(.metric, mean) %>%
  mutate(model = "Penalized Regression")

# summarize random forest metrics using the best tuned settings
rf_best_metrics <- rf_metrics %>%
  filter(mtry == best_rf$mtry, min_n == best_rf$min_n) %>%
  filter(.metric %in% c("rmse", "rsq")) %>%
  select(.metric, mean) %>%
  mutate(model = "Random Forest")

# combine metrics from all models into one table
model_comparison <- bind_rows(
  lm_metrics,
  glmnet_metrics,
  rf_best_metrics
)

# present the comparison table in a wide format
model_comparison %>%
  pivot_wider(names_from = .metric, values_from = mean) %>%
  mutate(
    rmse = round(rmse, 3),
    rsq = round(rsq, 3)

Three models were evaluated using cross-validation: a linear regression model, a penalized regression model (LASSO), and a random forest model. The linear and penalized models performed almost identically (RMSE ≈ 0.677), suggesting that regularization did not provide much benefit. The random forest model achieved the lowest RMSE (~0.670), indicating slightly better predictive performance. Although the improvement was small, the random forest was selected as the final model because it can capture nonlinear relationships and interactions between predictors, which are likely present in ecological data.

Discussion

This analysis explored whether environmental conditions influence bird abundance and whether these effects differ across species. The exploratory analysis showed that bird counts are highly skewed, with many small observations and a few extremely large values. After log-transforming the outcome, model performance improved substantially and made it easier to identify relationships in the data.

Across all three models, performance was fairly similar, with the random forest model performing slightly better than the two linear approaches. This suggests that while some nonlinear relationships or interactions may be present, the overall structure of the data is not extremely complex. Species identity consistently played an important role, indicating that differences among species explain more variation in bird counts than environmental conditions alone.

Although the final model performed reasonably well, the residual analysis showed that some variation remains unexplained. Overall, environmental conditions do appear to influence bird abundance, but much of the variation is driven by species-specific differences and other unmeasured factors. This highlights both the value and the limitations of predictive modeling in ecological data. Future work could improve performance by incorporating additional predictors such as spatial location, finer-scale temporal information, or species-specific ecological traits.
