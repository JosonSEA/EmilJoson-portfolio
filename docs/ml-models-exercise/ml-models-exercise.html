#define recipe: outcome is Y, predictors are all other variables
rec <- recipe(Y ~ ., data = data) %>%
  step_dummy(all_nominal_predictors()) #for handling non-numeric variables

##MODELING

#define linear regression model
lm_mod <- linear_reg() %>%
  set_engine("lm")

#create workflow
lm_wf <- workflow() %>%
  add_model(lm_mod) %>%
  add_recipe(rec)

#fit model

#LASSO MODEL

Tuning the models

##LASSO
#create a recipe for the LASSO model
lasso_rec <- recipe(Y ~ ., data = data) %>%
  step_dummy(all_nominal_predictors()) %>%
  step_normalize(all_predictors())

#define the LASSO model
lasso_mod_tune <- linear_reg(
  penalty = tune(),
  mixture = 1
) %>%
  set_engine("glmnet")

#combine the recipe and model into a workflow
lasso_wf_tune <- workflow() %>%
  add_recipe(lasso_rec) %>%
  add_model(lasso_mod_tune)

#create a grid of 50 penalty values from 1e-5 to 1e2
lasso_grid <- tibble(
  penalty = 10^seq(-5, 2, length.out = 50)

#I think the LASSO tuning results show that the model performs best when the penalty is very small because at that point it’s basically acting like a regular linear regression with almost no shrinkage. As the penalty increases, the model starts shrinking the coefficients more, which simplifies things but also removes useful information from the predictors. Because of that, the predictions get worse and the RMSE increases. I think the RMSE doesn’t go lower than the linear model because LASSO is still a linear method, so it can’t really do better than the ordinary least squares fit on the same data. Since we’re using apparent resampling and evaluating on the same data we trained on, the full linear model already gives the best possible fit, and adding any penalty just makes the model perform worse.

#I think the main reason the RMSE increased for both models when using cross-validation is because the models are now being evaluated on unseen data instead of the same data they were trained on. When we used apparent resampling before, the models were essentially being tested on the training data, so the performance looked much better than it actually was. With cross-validation, the models have to make predictions on new data, which gives a more realistic estimate of performance, so the RMSE increases. 
# 
# For the LASSO model, I still see that the best performance happens at very small penalty values. I think this is because when the penalty is close to zero, the LASSO behaves almost like a regular linear model and keeps most of the useful information from the predictors. As the penalty increases, the coefficients are shrunk more, which removes important information and leads to worse predictions.
# 
# For the random forest, I think it performed much better before because it is a very flexible model and was likely overfitting the training data. With cross-validation, that overfitting is penalized because the model is tested on unseen data, so its performance drops a lot. Compared to LASSO, the random forest now has a higher RMSE, which suggests it does not generalize as well in this case.
# 
# Overall, I think the LASSO model performs better because it has a lower RMSE under cross-validation, meaning it makes more accurate predictions on new data.
